I took it upon myself to use as minimal AI as possible and learn more stuff; as is, AI is probably the best learning tool humanity has ever made, though unfortunately people are wont to use a crutch; I know as a fact I use LLM search engines as an easy way often, and I worry I'll lose some of the critical thinking skills that come along with the challenge of learning independently. I've started with microelectronics, though it's kinda cheating as I have a baseline knowledge.


## Patch notes

### Stars!!!

![check these bad boys out](./gifs.stars.gif)

Dude I did this in like an hour. No, I did not master 2d animations and shit, I just used some library code, but it's pretty wicked how much easier this is now my brain is somewhat more developed. Did you know that a USB-C gets really fucking hot? Electricity!

Before this, I got a temperature sensor working. Plan is to combine them, and stick them in a little 3d printed box. I don't have a printer, but I also feel like this little shitter could be put into a takeout box and look right at home. For now, between shifts, little bit of code here and there to get the brains working first. Maybe I should buy some cailpers? Are they even called that?
